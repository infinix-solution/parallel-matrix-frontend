# Frontend Assets

Drop these files here for full visuals:

- `logo.jpeg`      — your brand logo (used in navbar, footer, intro loader)
- `hero-bg.jpg`    — default hero background (used if no slider uploaded)
- `about.jpg`      — about section image
- `gunjan.jpg`     — team photo
- `devyani.jpg`    — team photo
- `ashwini.jpg`    — team photo
- `placeholder.jpg` — fallback for missing team photos

If any of these are missing, the section will still render — broken `<img>` tags
will simply show no image.
